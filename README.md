# astrbot_plugin_video_watcher

让 AstrBot 里的机器人能「看」视频。

## 它解决什么问题

AstrBot 收到视频时，只有在上下文里追加一行路径：

```python
# astr_main_agent.py
text = f"[Video Attachment: name {video_name}, path {video_path}]"
```

模型本身没有视频解码能力，所以它只知道「有个文件在这」，看不到画面。

这个插件补上中间那一步：**用 ffmpeg 抽帧 → 把帧图交给多模态模型 → 返回文字描述**。

也支持群里分享的 **B 站视频链接、b23.tv 短链接和 QQ 分享卡片**：先解析并下载视频，再抽帧观看。引用别人分享的消息也可以使用。

## 前提

- AstrBot `>= 4.24.0`
- 当前对话模型**支持图片输入**（不支持会报错，例如纯文本模型）
- 依赖 `imageio-ffmpeg`（会自带静态 ffmpeg，不需要系统预装）
- B 站链接下载依赖 `yt-dlp`，运行 AstrBot 的机器需要能访问 B 站及其视频服务器

## 安装

### 方式一：AstrBot 插件市场

搜索「视频观察员」，或直接填仓库地址。

### 方式二：手动

```bash
cd AstrBot/data/plugins
git clone https://github.com/wuyinhh/astrbot_plugin_video_watcher.git
cd astrbot_plugin_video_watcher
pip install -r requirements.txt
```

装完重启 AstrBot，插件页应该能看到「视频观察员」。

### 更新已有插件

在 AstrBot 的「已安装」插件页面找到「视频观察员」，点击 **更新**。更新会下载仓库的新代码，并检查安装依赖、重新加载插件。**重载**只加载本地现有代码，不会从 GitHub 下载更新。

更新后检查版本号是否为 `0.2.0`，再用 `/看视频` 测试。如果提示缺少依赖，可以在 **AstrBot 使用的 Python 环境**和插件目录中执行下面的命令，再重载插件：

```bash
python -m pip install -U -r requirements.txt
```

## 用法

支持以下触发方式：

| 方式 | 说明 |
|---|---|
| `/看视频` + 一条视频 | 最直接 |
| 引用一条视频消息，再发 `/看视频` | 不用重复上传 |
| `/看视频 https://www.bilibili.com/video/BV...` | 读取 B 站视频，支持带 `?p=2` 的分 P 链接 |
| `/看视频 https://b23.tv/...` | 自动解析短链接 |
| 引用别人发的 B 站链接或 QQ 分享卡片，再发 `/看视频` | 从引用消息中提取视频地址 |
| 引用分享消息并 @机器人，说「帮我看看这个视频」 | 对话模型在需要时调用 `describe_video` 工具 |

普通聊天仍遵循 AstrBot 原有的唤醒规则。仅在群里发送卡片不会强制机器人回复，也不会自动下载所有群视频。分享卡片的地址会在本轮模型请求前补入上下文；需要启用 `describe_video` 工具，并使用支持工具调用及图片输入的模型。若模型没有主动调用，可以直接使用 `/看视频`。

引用功能依赖 QQ 适配器提供被引用消息的内容。若引用消息无法取回，请直接复制链接发送。同一条命令有多个链接时只处理第一个。

正常对话示例：

> 你：（发一个视频）/看视频
> 她：画面里是一个厨房，有个人在切菜，台面上放着两个碗……

## 配置

参数写在 `main.py` 顶部，改完重启生效：

| 变量 | 默认 | 说明 |
|---|---|---|
| `MAX_FRAMES` | 6 | 抽几帧。帧数越多越贵，6 帧通常够描述 |
| `FRAME_WIDTH` | 640 | 帧图宽度。越大越清晰，token 也越多 |
| `MAX_VIDEO_MB` | 500 | 超过这个大小直接拒绝 |
| `FFMPEG_TIMEOUT` | 180 | 单次 ffmpeg 超时（秒） |
| `DOWNLOAD_TIMEOUT` | 180 | B 站短链解析和下载总超时（秒） |

B 站下载优先选择 720p 及以下的视频流；只下载画面，不额外下载音轨。视频流不可访问时会尝试其他可用格式。每次只处理一个视频/分 P，最多同时处理两条链接；下载文件和帧图在处理结束、失败或取消后清理。

## 局限

**它看的是「几张截图」，不是视频。**

- 能看出：场景、人物、物体、正在做的事、画面上的文字
- 看不出：连贯动作、镜头运动、说了什么（声音）、剧情因果

想要声音，得另外接 ASR（例如 faster-whisper）把音轨转成字幕，再把文字一起喂给模型。

B 站链接仅支持普通投稿视频页，不支持直播、用户主页、动态页或番剧页。不读取浏览器登录信息；需要登录、付费、地区受限、已删除或被 B 站限制访问的视频可能下载失败，此时可以直接发送你能正常获取的视频文件。链接失效或下载异常时不会把卡片标题当成已观看的视频内容。

## 实现细节

1. `ffmpeg -i` 解析时长（解析 stderr 的 `Duration:`）
2. 按 `duration * (i + 0.5) / MAX_FRAMES` 均匀取 6 个时间点，各自 seek 抽 1 帧
3. 缩放到 `FRAME_WIDTH`，JPEG 质量 3
4. 帧图路径直接传给 `provider.text_chat(image_urls=[...])`，由 AstrBot 内部转成 data URL
5. 临时目录用完即删

拿不到时长时（流式/损坏文件）退化为 `fps=1/5` 固定间隔抽取，最多 6 帧。

`bilibili.py` 负责 B 站链接规范化、短链跳转检查和下载。下载在独立子进程中执行，超时或取消时停止子进程并等待退出，再清理临时目录。

```bash
python -m unittest discover -s tests -v
```

离线测试覆盖 QQ 卡片和引用消息解析、工具调用入口、短链跳转检查、下载失败/超时/取消和临时文件清理。测试中的 AstrBot 接口使用替身；上线前仍需在实际 QQ 群和模型环境验证。
